# 🎯 Game Objective
The main objective is to collect 10 coins while avoiding the enemies.
- 🪙 Collect coins → Increase your score.
- 🔴 Hit an enemy → Lose one life.
- 🏆 Reach 10 coins → You Win!
- 💀 Lose all 3 lives → Game Over!
